Lightweight Brain Vessel Segmentation via Knowledge Distillation

A 6.23M-parameter student model that predicts 42 cerebral vessel classes from CTA and MRA volumes. The model runs on the mobile device via ONNX Runtime Web, with no server-side inference.

About this project

This project applies knowledge distillation to 3D cerebrovascular segmentation. A high-capacity nnU-Net teacher, provided as a Docker image, produces reference segmentations. A compact 3D U-Net student is trained to reproduce the teacher's outputs with substantially fewer parameters, so that inference becomes feasible on a mobile phone. The student is exported to ONNX and executed in the browser via ONNX Runtime Web.

Definitions

Teacher model
An nnU-Net ensemble covering 5 anatomical regions across 11 fold-models, totalling 970M parameters (8.29 GB Docker image). It serves as the reference model and runs on a workstation GPU.
Student model
A compact 3D U-Net with 6.23M parameters (25 MB ONNX file). It is trained to match the teacher's segmentation outputs and runs entirely on the mobile device.
Voxel
A volumetric pixel. CT and MRA volumes are dense 3D grids of voxels, for example 147 x 176 x 158 (4.1 million voxels). Segmentation assigns a vessel class label to each voxel.
Vessel class
A named cerebral blood vessel, such as R-ICA, L-M1, or Basilar artery. The TopBrain dataset defines 42 vessel classes plus background.
Dice score
A measure of voxel-set overlap between a prediction and the ground truth. Ranges from 0 (no overlap) to 1 (perfect overlap). The merged score treats all vessels as one class. The macro score averages per-class Dice across vessel classes present in the ground truth.
Dataset
TopBrain 2025, released by the University of Zurich. 25 patients, each with a CTA and an MRA volume (50 volumes total), annotated with 43 classes. This interface uses the 10 held-out test volumes.

Interface overview

  • Test cases: 5 patients, each with a CTA and an MRA scan, held out from training. Every case has teacher prediction and ground-truth annotations bundled for comparison.
  • Metrics panel: teacher and student Dice scores, computed against the ground truth for the selected case.
  • Viewer: three orthogonal planes (axial: top-down, coronal: front, sagittal: side). Overlays show ground truth in red, teacher in blue, student in green.
  • Upload: accepts NIfTI volumes (.nii.gz) for inference. All preprocessing and inference occur locally in the browser.
